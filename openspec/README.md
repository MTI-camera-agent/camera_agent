# OpenSpec（CameraAgent）

本目录由 [OpenSpec](https://github.com/Fission-AI/OpenSpec) 管理。

| 路径 | 含义 |
|------|------|
| `config.yaml` | 项目 context 与 artifact 规则 |
| `specs/` | 当前系统行为（archive 后累积） |
| `changes/` | 进行中的变更包 |
| `changes/archive/` | 已完成变更（archive 后） |

工作流见 **[docs/协作与规格驱动说明书.md](../docs/协作与规格驱动说明书.md)** 与 [docs/agents/skills.md](../docs/agents/skills.md)。

Cursor：`/opsx-propose "your idea"` 开始第一个 change。
