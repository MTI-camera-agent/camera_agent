# Architecture Decision Records

Hard-to-reverse decisions for CameraAgent. Create an ADR when **all** are true:

1. Cost of reversing later is meaningful
2. Future readers will wonder "why this way?"
3. Genuine trade-offs existed

Format: see [reference/skills/skills/engineering/domain-modeling/ADR-FORMAT.md](../../reference/skills/skills/engineering/domain-modeling/ADR-FORMAT.md).

Naming: `NNNN-short-title.md` (e.g. `0001-flux-primary-reference-preview.md`).

Do **not** put acceptance criteria or full feature specs here — use `openspec/changes/`.
