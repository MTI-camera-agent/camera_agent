  • 状态：设计稿（未编码）；对应 01-MVP期-方案设计及计划.md §5 Phase 3–5 / §9.2 / 附录 A.4–A.5
  • 可预览草稿：ios_app_ux_v1.html（v2.0，浏览器直接打开）；旧版 ios_app_ux.html（v1.1，已被取代，保留作参考）
  • 视觉令牌：沿用 frontend/web/styles.css（ink/lake/mist + Fraunces/IBM Plex Sans）

App 打开即相机（iOS 相机风），无独立 Home。CameraAgent 由相机右上 ✦ 轻量唤起：端侧 VLM 读预览 + skill 白名单给 1~5 候选，文字/语音默认隐藏，点✎才唤起。Plan 3~5 步左侧竖向圆点连线、提示不约束；目标交端侧 VLM 持续 Evaluation（容差范围）+ 择机抓拍；中途跳走→提醒结束。

1. 三大场景（UX 入口，融合流程）

场景 定位 说明
给自己拍 分身入画（dual-cam-clone） 独立开关：打开→前置自拍→生成分身→置入后置预览→后续与"给他人拍"一致。见 03-场景设计及Skills实现.md
给他人拍 人像引导 skill：给女朋友拍照（耐心/时长/容忍交互多）、给孩子拍照（即时/抓拍/孩子不听引导、主要引导拍摄者）…
拍景 场景引导 skill：拍摄美食、拍摄古典建筑、拍摄湖景…

3 大场景 = skill 分类底色，不做显式 3 段选择器；✦ 面板直接显 VLM 候选 chip（按当前预览 match 白名单 1~5 个，相关度排序）+ 独立"给自己拍"开关 + ✎自定义。

2. 设计原则（v2.0）

  1. 相机即根屏：App 打开即相机，无独立 Home；agent_panel / question / plan_active / 倒计时 / done 都是相机之上的层。
  2. 不干扰取景：✦ 面板默认只显候选 chips + 给自己拍开关 + ✎；文字/语音隐藏，点✎才唤起；Act 期底栏 chrome 隐藏。
  3. 端侧 VLM 候选即入口：✦ → 端侧 VLM(MiniCPM, Demo mock) 读预览 + skill 白名单 → 1~5 候选 chip；点 chip = 触发该 skill（无文字、无 Question）。
  4. 给自己拍 = 开关：打开 → 前置自拍 → 分身 → 置入后置预览 → 后续与给他人拍一致。
  5. Plan 轻约束：3~5 步、左侧竖向圆点连线、√完成、提示不约束；目标交端侧 VLM 持续 Evaluation（容差范围，在范围即完成）；择机抓拍；中途跳走/自行拍摄→提醒结束。
  6. Question 仅自定义文字触发：候选/给自己拍→无 Question；✎ 输入文字→可能 Question。

3. 状态机（相机常驻根屏）

camera(home) ──(✦)──► agent_panel
agent_panel ──(VLM候选 chip)──────────────────────► plan_active   [无 Question]
agent_panel ──(给自己拍 开关)──► clone_id(前置自拍 mock)──► plan_active(分身置入)
agent_panel ──(✎ 输入文字+↗)──► [可能] question ──► plan_active
plan_active = camera + 左侧 Plan 步骤条(√推进) + overlay(框/箭头/锚点/目标图) + 顶部 Agent 文字
   plan_active ──(端侧VLM 持续 Evaluation)──► 步骤√推进 / overlay 演化 / 择机抓拍 capture
   plan_active ──(severe)──► severe_banner（非阻塞）
   plan_active ──(场景失效)──► plan_refresh_modal ──► re-Plan
   plan_active ──(用户中途跳走/自行拍摄)──► end_remind（提醒流程结束）──► camera/done
   plan_active ──(capture_ready)──► capture(3s 倒计时)──► done──► camera

Plan 步骤示例（3~5）：① 粗调 机位/站位 ② 目标示意图就位 ③ 细调 姿态/视角 ④ 拍摄完成。plan_active 单屏，overlay 随步骤演化（粗→ref→细），不再分粗/细独立子屏。

4. 屏规格（iOS 相机风 + App 品牌）

屏 触发 内容
Camera（home） 启动 全屏取景；顶栏（左⚡/◐，右**✦ CameraAgent**）；底栏 = 变焦 .5/1x/2/4/8 + 模式条 + 快门⦿ + 相册缩略图(左下，仅回看) + 翻转↻。✦ → agent_panel
Agent Panel（默认态） ✦ 点按 变焦数字上方的紧凑半透明 blur 面板：①VLM 候选 chips（1~5，scene-matched）点 chip=捕获当前帧+分析（无 Question）；②🤳 给自己拍开关（独立）→ clone_id；③**✎ 自定义**按钮（点按才唤起文字输入+🎤+↗）；✕dismiss。无显式文字框。3 大场景为 skill 分类底色
Agent Input（✎ 唤起） ✎ 点按 在 ✦ 面板内唤起文字输入框 + 🎤(未来语音 disabled) + ↗发送；输文+↗ → question（可能）
Clone ID（给自己拍） 开关打开 前置自拍框 + 提示"拍上半身生成分身" + 快门（mock 一键）→ 切后置预览（含分身）→ plan_active。标注 identity-photo-gen 待建
Question ✎ 自定义文字 相机之上底部 sheet：draftGoal + 可折叠"冲突摘要" + 1~2 问题卡(option chips) → plan_active。仅自定义文字触发；候选/给自己拍不触发
Plan Active（核心） 候选/开关/确认 相机全屏 + 左侧竖向 Plan 圆点连线（3~5 步，✓/▶/○）+ 顶部 Agent 文字提示（居中靠上）+ 中部 overlay（bbox/箭头/锚点/三分线/目标图）+ 右上 score 环 + 右下紧凑 Eval 控制；步骤随端侧 Eval √ 推进；Act 期底栏 chrome 隐藏
Capture 择机抓拍/captureReady 相机 + 绿色就绪环 + 3s 倒计时 → 快门
Done 拍摄完成 成片 + Plan 摘要(全✓) + "再拍一组"(→camera)/"完成"；场景二标注后处理 P4+

4.1 Plan Active 子演化（overlay 随步骤）

  • step1 粗调：bbox(目标区)+箭头(移动方向)+锚点(站位/对焦点)+三分线；advice"人物向右移至右三分线"。
  • step2 目标示意图就位：+ PIP 目标图（ready，latencyMs/generator）；advice"对照示意图"。
  • step3 细调：目标图 alpha@0.35 叠加 + 对齐进度条(progressScore)；advice"头部再微转"。
  • step4 拍摄完成：全✓ → capture_ready → 倒计时。
  • severe：连续偏离→顶部红横幅（非阻塞）+退出/继续。
  • plan_refresh：场景失效→模态"重新规划"。
  • end_remind：用户跳走/自行拍摄→模态"流程已结束，保留/丢弃"。

5. 技术结论（Q：能否调起 iPhone 相机系统组件？）

不能嵌入原生 iOS"相机"App UI：无公开 API；UIImagePickerController(.camera) 模态、不可定制、不允许 overlay。唯一路径：用 expo-camera（App 已选定，见 01-MVP §9.2）自建全屏取景，复刻 iOS 相机主要功能（实时预览 / takePictureAsync 抓拍 / cameraType 翻转 / flashMode / zoom 变焦 .5/1x/2/4/8），并可画 overlay + ✦ 面板（系统相机禁此）。Instagram/Snapchat 同法。> 变焦 .5/2/4 依赖设备多摄，Phase A 核实可用 ratio。

6. 端侧 VLM 架构注（P5 能力前移）

v2.0 的端侧 VLM(MiniCPM) 候选建议 + 持续 Evaluation + 择机抓拍 + 中途结束提醒属 01-MVP §5 Phase 5 的端侧能力前移到默认 UX。

  • Demo：mock 候选 + mock Eval 推进。
  • 开发期兜底：可云端 Qwen3-VL :8000 describe_scene 出候选（非端侧，但能跑通）。
  • 真功能：需端侧 MiniCPM（重）或端侧化部署。

⚠️ 此为重要架构决策；落地前需评估端侧可行性/性能/发热，并在 01-MVP §9.2 增补"端侧 VLM 候选/Eval"为 Phase 前置项（现 §9.2 Phase A–D 偏云端 Act，端侧候选/Eval 需补）。

10. iOS 惯用 UI 约定

  • 相机即主界面：全屏取景（expo-camera），iOS 原生相机范式。
  • ✦ 右上触发：唤起贴底半透明 ✦ 面板（候选+开关+✎，变焦数字上方）。
  • 左侧 Plan 圆点连线：竖向、窄、半透明，✓/▶/○；提示不约束。
  • 顶部 Agent 文字：居中靠上 advice pill。
  • Act 期 chrome 隐藏：底栏 chrome 隐，换紧凑 Eval 控制（右下）；不干扰取景。
  • Bottom sheet：Question 用底部 sheet。
  • 进度环/条：右上 compositionScore 环；progressScore 条。
  • 倒计时：大号 3→2→1 + 绿色就绪环。
  • 横幅/模态：severe 顶部红横幅（非阻塞）；plan_refresh/end_remind 居中模态。
  • 🎤 语音：✎ 唤起内，未来支持语音输入意图。
